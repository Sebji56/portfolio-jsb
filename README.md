# portfolio-jsb

Site portfolio de Jean-Sébastien Bisson (« Seb Ji ») — développement des affaires et vente-conseil en solutions technologiques.

Construit avec [Astro](https://astro.build) et Tailwind CSS, avec l'aide de Claude Code. La démarche est documentée dans [JOURNAL_IA.md](JOURNAL_IA.md).

## Démarrer en local (PowerShell)

```powershell
npm install
npm run dev
```

Puis ouvrir http://localhost:4321.

Le guide de mise en ligne pas à pas sera ajouté à la fin de la construction.
